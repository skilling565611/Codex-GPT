# Codex-GPT

Workspace for Codex and GPT experiments.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
```

## Checks

```bash
python -m pytest
```

## Project Layout

```text
src/codex_gpt/   Python package source
tests/           Test suite
docs/            Project notes and planning
.github/         GitHub templates and CI
```
